# Bài học CHUNG (mọi sản phẩm)

Bài học về **cách dựng** — đúng với mọi sản phẩm. Bài học về nội dung/hook/preset của từng sản phẩm ghi ở
`profiles/<hồ sơ>/learnings.md`. Skill `video-learnings` quyết định ghi vào đâu: liên quan cắt, nhịp, chữ, vùng an toàn,
né mặt, âm thanh, cách làm việc → file này; liên quan sản phẩm/khách/hook/preset của hồ sơ → file của hồ sơ.

Mỗi dòng: `YYYY-MM-DD — bài học — bằng chứng (hồ sơ/lô/biến thể, điểm/số liệu)`. Không xoá bài học cũ trừ khi dữ liệu mới bác bỏ (gạch `~~…~~` + dòng mới).
